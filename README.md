# Unity-FPS-Ink-Trial

基于 Unity 的中国风水墨场景第一人称射击试炼 Demo。  
本项目用于 Unity3D 程序设计课程大作业展示。

## 项目简介

本项目在第一人称射击玩法基础上，结合中国风水墨场景，构建了一个可运行、可演示的射击试炼 Demo。

玩家可以在水墨山水、亭台、栈道等中国风场景中进行移动、瞄准和射击。项目整体以“水墨秘境试炼”为主题，在保留 FPS 基础交互的同时，体现中国传统山水意境与古风场景元素。

## 技术栈

- Unity 2021.3.29f1
- C#
- Unity UI
- FPS Controller
- Windows Build
- Django 后端服务
- 房间模式 / Room 管理

## 当前版本

当前发布版本：`v0.1.0`

已发布 Windows 可运行 Demo，可在 GitHub Releases 页面下载压缩包后解压运行。

## 功能说明

当前 Demo 包含以下内容：

- 第一人称玩家控制
- 鼠标视角控制
- 基础射击逻辑
- 弹药数量显示
- 生命值 UI 显示
- 中国风水墨场景
- Windows 平台可执行版本
- Django 后端房间数据管理

## 后端说明

本项目包含 Django 后端服务，用于维护 FPS 房间信息。

后端管理页面可查看房间数据，例如：

```txt
Room 7777 - 7777
```

后端服务主要用于课程展示中的房间管理与项目结构说明，体现 Unity 客户端与 Django 服务端结合的项目特点。

> 注意：后台账号、密码等敏感信息不写入公开仓库。

## 运行方式

### 方式一：运行 Release 版本

1. 打开 GitHub Releases 页面；
2. 下载 `v0.1.0-Windows.zip`；
3. 解压压缩包；
4. 双击 `.exe` 文件运行游戏。

### 方式二：使用 Unity 打开项目

1. 使用 Unity 2021.3.29f1 打开项目；
2. 打开主场景：

```txt
Assets/Scenes/SampleScene.unity
```

3. 点击 Play 运行。

## 操作方式

```txt
W / A / S / D：移动
鼠标移动：控制视角
鼠标左键：射击
```

## 项目亮点

### 中国风水墨场景

项目采用中国风水墨场景作为主要关卡环境，将 FPS 玩法与山水、亭台、栈道等传统意境元素结合，使课程项目更贴合中华优秀传统文化主题。

### 第一人称射击交互

项目实现了第一人称移动、视角控制、射击反馈、弹药显示和生命值 UI 等基础 FPS 交互内容。

### Django 后端房间模式

项目包含 Django 后端服务，用于维护房间信息。相比普通单机 Demo，本项目具备一定的客户端与服务端协作结构。

### Windows 可运行版本

项目已完成 Windows 平台打包，并通过 GitHub Release 发布，便于小组成员、老师或答辩展示时直接下载运行。
