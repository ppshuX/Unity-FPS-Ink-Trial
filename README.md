# Unity-FPS-Ink-Trial

## 项目简介
中国风水墨场景第一人称射击试炼游戏。项目在原有 FPS 联机射击基础上，新增了可直接演示的单人试炼模式、波次靶场、评分 HUD、连击/精准命中奖励、命中特效和移动射击手感优化，适合作业展示与现场答辩。

## Unity 版本
Unity 2021.3.29f1c2

## 已完成增强
- 单人试炼入口：主菜单点击 `LOCAL TRIAL`，或按 `L`，无需后端房间接口即可本地启动。
- 波次靶场玩法：自动生成水墨机关靶，后续波次增加移动靶、更高血量和更密集挑战。
- 敌方魂影：第二波开始生成追击玩家的水墨魂影，靠近后会造成伤害，击破可获得额外分数和时间；每 3 波出现精英魂影作为小 Boss。
- 场内补给：随机生成生命、弹药、时间、分数四类补给，鼓励玩家边移动边作战。
- 评分系统：命中、精准命中、破坏机关、击破魂影、拾取补给、连击、清波都会给分，并保存本地最高分。
- 挑战目标：HUD 底部显示命中率、最大连击、补给收集、精英击破四类可完成目标。
- 现代 HUD：显示分数、最高分、波次、倒计时、剩余目标、魂影数量、补给数量、命中率、生命和冲刺冷却。
- 结算评级：试炼结束后显示 S/A/B/C/D 评级、最终分数、最高分、命中率、最大连击、击破数、补给数、成就徽章和奖励分。
- 危险预警：魂影接近玩家时 HUD 会显示距离预警，提示玩家 Dash 或转火。
- 暂停系统：按 `P` 可暂停/继续，暂停层显示继续、重开和鼠标释放提示。
- 射击反馈：中心命中标记、得分浮字、子弹轨迹、目标破碎粒子、目标受击变色、受伤红屏反馈。
- 手感优化：冲刺、短距 Dash、跳跃缓冲、空中控制、瞄准 FOV、冲刺 FOV、镜头步行动效、武器轻微摆动。
- 场景氛围：试炼开始后自动生成边界灯柱，配合雾效、环境光和发光材质强化水墨试炼感。
- 流畅度优化：运行时默认 120 FPS、60Hz 物理步进、刚体插值、连续碰撞和雾效/环境光调整。
- 稳定性补强：玩家注册容错、UI 空引用保护、射击目标判定、Respawn 位置推荐、调试扣血仅限 Unity Editor。

## 运行方式
使用 Unity 2021.3.29f1c2 打开项目，打开 `Assets/Scenes/SampleScene.unity`，点击 Play 运行。

推荐演示流程：
1. 点击主菜单 `LOCAL TRIAL`，或直接按 `L`。
2. 使用 `WASD` 移动，`Shift` 冲刺，`Ctrl` 或鼠标中键短距 Dash，鼠标左键射击。
3. 按 `R` 换弹，`Q` 或数字键 `1/2` 切换武器，鼠标右键聚焦瞄准，`P` 暂停。
4. 在 90 秒内尽量打掉更多机关靶，躲避并击破魂影，拾取补给延长节奏。
5. 按 `T` 可重新开始试炼，按 `Esc` 释放鼠标。
